# Internationalization (i18n)

- **No Hardcoded Display Strings**: Never hardcode user-facing strings (labels, titles, messages, units, badges, countdown formats, or status hints) in either frontend components or backend logic.
- **Frontend Localization**: In Svelte components and frontend TypeScript/JavaScript files, always use `t('ui.path.to.key', { ... })` imported from `@/lib/i18n`.
- **Backend Localization**: Store all application UI strings in `lang/zh_TW/ui.php`. In PHP controllers, actions, and services that generate user-facing text or Inertia payloads, always retrieve translations using `__('ui.path.to.key', [ ... ])` or `trans('ui.path.to.key', [ ... ])`.
