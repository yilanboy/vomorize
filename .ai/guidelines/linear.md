# Linear Project Management & Specification

- **Project Management**: All project tasks, issues, and development workflows are managed on Linear. Always use the `linear` MCP server tools to interact with tasks.
- **Specifications & Documents**: The official Vomorize product specifications, SRS learning flows, and business requirements are documented in Linear Documents. Before planning or implementing features, consult the relevant Linear Documents (using `list_documents` and `get_document`) to verify specifications and acceptance criteria.
- **Task Workflow**:
    - Verify or create the corresponding Linear issue before beginning feature development.
    - Maintain issue status (`In Progress`, `In Review`, `Done`) and post concise completion summaries as comments upon finishing work.
