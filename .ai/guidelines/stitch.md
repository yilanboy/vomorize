# Google Stitch UI/UX Design

- **UI/UX Prototyping & Fine-Tuning**: Page designs and layout specifications are drafted, previewed, and fine-tuned using Google Stitch before frontend implementation.
- **Stitch MCP Integration**: Use the `stitch` MCP server tools (such as `list_screens`, `get_screen`, `generate_screen_from_text`, and `generate_variants`) to inspect and reference screens in the Vomorize Stitch project (`4567702977063161754`).
- **Core Design Constraints**:
    - Minimum font size is 14px (`text-sm`). Strictly NO `text-xs` (12px).
    - Palette: Neutral Slate/Zinc neutrals, Primary Blue (`#2563eb`), Emerald Green (`#059669`) for completion/success. Strictly NO purple or violet.
    - Native support for both Light and Dark themes.
    - Prioritize clean, minimal layouts without redundant banner explanations or clutter.
